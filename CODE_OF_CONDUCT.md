# Code of Conduct

Participation in Vacation Rental Protocol projects follows the existing [VRP Contributor Covenant Code of Conduct](https://github.com/vacationrentalprotocol/vrp-spec/blob/main/CODE_OF_CONDUCT.md).

That policy defines expected behavior, scope, enforcement responsibilities and reporting procedures for the community.

Report conduct concerns privately to **hello@vacationrentalprotocol.com**, with `VRP CONDUCT` in the subject, as specified in that policy. Do not publish another person's private information in an issue.
