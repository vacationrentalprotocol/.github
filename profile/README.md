# Vacation Rental Protocol (VRP)

An open protocol that lets AI agents verify host-signed vacation rental offers and direct guests to the host’s own booking website.

The host’s domain is the source of truth. Offers carry exact pricing, availability, expiry and a direct booking URL, signed with Ed25519.

Anyone can implement VRP. No central marketplace, required registry or operator approval.
